In this article we will visit the idea of coupled oscillator to visualise the world of frequency space, linear algebra and fourier transform. You will be surprised how all these concepts arise from a simple physical system and how simple ideas can be extrapolated to different concepts.

What is coupled oscillator?

A coupled oscillator are set of oscillators connected through an energy transfering components. Simply speaking, connect two harmonic oscillator with each other using something which can transfer energy and store it.

The most basic example of a coupled oscillator is two spring oscillators connected via a third spring. Through out this article we will use this system as our primary example, covering the following topics:

Free body diagram

Before we start creating free body diagrams and write out equation of motion for each masses, we need to clear out few assumptions.
  • Both masses $m$ are equal
  • All the three springs have same stiffness i.e. $k$
  • Left wall lies on $x = 0$ coordinate
Now looking at block 1, we can assume a slight displacement $x_1$ towards right. This causes spring 1 to extend.
Similarly for block 2, we can assume a slight displacement $x_2$ towards right. This causes spring 3 to compress. For spring 2, it will pull block 1 with $k(x_2-x_1)$ and block 2 with $-k(x_2-x_1)$. Keeping displacement terms in order: $-k(x_1-x_2)$ and block 2 with $k(x_1-x_2)$. Equating forces on each masses we get following equations of motion: $$-kx_1 - k(x_1 - x_2) = m\ddot{x_1} \tag{1}$$ $$-kx_2 + k(x_1 - x_2) = m\ddot{x_2} \tag{2}$$

Solving Equations of Motion (Algebraically)

To solve equations $1$ and $2$ we can use a trick. We can add and subtract both equations to get a new set of equations which are equivalent to original. $$-kx_2 + k(x_1 - x_2) + kx_1 + k(x_1 - x_2) = m(\ddot{x_2} - \ddot{x_1})\tag{2 - 1}$$ $$-3k(x_1 - x_2) = m(\ddot{x_1} - \ddot{x_2})\tag{2 - 1}$$ $$-kx_2 + k(x_1 - x_2) - kx_1 - k(x_1 - x_2) = m(\ddot{x_2} + \ddot{x_1})\tag{2 + 1}$$ $$-k(x_1 + x_2) = m(\ddot{x_1} - \ddot{x_2})\tag{2 + 1}$$ We can see that there are two equation in form of $(x_1 - x_2)$ and $(x_1 + x_2)$. Naming them $x_{+} = x_1 + x_2$ and $x_{-} = x_1 - x_2$. We get
$$-kx_{+} = m\ddot{x}_{+}$$ $$-3kx_{-} = m\ddot{x}_{-}$$
The set of equations above are equivalent to the equations of simple harmonic motion ($-\omega^2x=\ddot{x}$).
In this case $\omega_{0} = \sqrt{\cfrac{k}{m}}$ and the solution to above equations are: $$x_{+} = A_{+}\cos(\omega_0t - \phi_{+})$$ $$x_{-} = A_{-}\cos(\sqrt{3}\omega_0t - \phi_{-})$$ Transforming $x_+$ and $x_-$ back to $x_1$ and $x_2$ we get: $$x_1 = \cfrac{1}{2}(x_+ + x_-)$$ $$x_{1} = \cfrac{A_{+}}{2}\cos(\omega_0t - \phi_{+}) + \cfrac{A_{-}}{2}\cos(\sqrt{3}\omega_0t - \phi_{-})$$ $$x_2 = \cfrac{1}{2}(x_+ - x_-)$$ $$x_{2} = \cfrac{A_{+}}{2}\cos(\omega_0t - \phi_{+}) - \cfrac{A_{-}}{2}\cos(\sqrt{3}\omega_0t - \phi_{-})$$ Since $A_+$ and $A_-$ arbitary constants we can absorb the factor of $1/2$ in them, resulting in: $$x_{1} = A_{+}\cos(\omega_0t - \phi_{+}) + A_{-}\cos(\sqrt{3}\omega_0t - \phi_{-})$$ $$x_{2} = A_{+}\cos(\omega_0t - \phi_{+}) - A_{-}\cos(\sqrt{3}\omega_0t - \phi_{-})$$

Linear Algebra

If we want to generalise coupled oscillators, we can start from the differential equation itself. Writing it in a concise way using vector notation gives us a new perspective for this problem. There are a lot of ways to visualise stuff and not visualising is also another way to visualise it.

In this case we are treating vectors in similar way.
For a physicist it might be an entity with direction and magnitude.
For students it might be something with origin and arrow-shaped head.
For mathematician it might be an entity which transforms like a vector (confusing but let's not go into this now).
For this particular case we are treating a vector for what it is in computer science i.e. "list of data points".

Using this as our understanding of vector, we can represent position of oscillators (blocks) as $ \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} $. Purely treating the two parameters as data points. Applying the derivative operator twice on this representation give us $ \begin{pmatrix} \ddot{x_1} \\ \ddot{x_2} \end{pmatrix} $ and using matrix multiplication rules we get to the equation below.

So not visualising at first and treating things as parameters helped us get to a more concise form of equation of motions. $$-kx_1 - k(x_1 - x_2) = m\ddot{x_1} \tag{1}$$ $$-kx_2 + k(x_1 - x_2) = m\ddot{x_2} \tag{2}$$ Substituting $\omega_0 = \sqrt{\cfrac{k}{m}}$ $$ \begin{pmatrix} \ddot{x_1} \\ \ddot{x_2} \end{pmatrix} = \begin{bmatrix} -2\omega_0^2 & \omega_0^2 \\ \omega_0^2 & -2\omega_0^2 \end{bmatrix} \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} $$ This looks very similar to differential equation $\ddot{x} = \alpha \cdot x$ but instead of $x$ and $\alpha$ being a scalar quantity they are now vectors and matrix respectively. $$\ddot{X} = \hat{\Omega}\cdot X$$ General solution to $\ddot{x} = \alpha \cdot x$ are of form $Ae^{s\cdot t}$ where $s \in \mathbb{C}$ and $A \in \mathbb{R}$. Extending it to vector form, general solution should be of form $\mathbf{A}e^{s\cdot t}$ where $s \in \mathbb{C}$ and $\mathbf{A} \in \mathbb{R}^2$.
Substituting this in the ODE, we get: $$\hat{\Omega}\cdot\mathbf{A}e^{s\cdot t} = s^2\mathbf{A}e^{s\cdot t}$$ $$\boxed{\hat{\Omega}\cdot\mathbf{A} = s^2\mathbf{A}}$$ This looks similar to the defining expression for an eigenvector. Exponential functions can be said as the eigenvector under derivative as transformation.
If we define eigenvector as following: $$\mathbf{A}\vec{v} = \lambda\cdot\vec{v}$$ i.e. an eigenvector is a vector which scales but preserves its direction under a linear transformation, in this case $\mathbf{A}$. The scaling factor $\lambda$ is known as eigenvalue.
If we generalise the above equation to an operator in place of a matrix (given that the operator is linear), we can say... $$\hat{\Omega}\psi=\lambda\cdot\psi$$ where $\psi$ is the eigenfunction.
If we assume the operator to be a derivative operator $D$ like $\cfrac{d}{dx}$ then we have... $$Df(x) = \lambda\cdot x$$ which by definition is family of exponential functions. $$\hat{\Omega}\cdot\mathbf{A} - s^2\mathbb{I}\mathbf{A} = \mathbf{0}$$ $$(\hat{\Omega} - s^2\mathbb{I})\mathbf{A} = \mathbf{0}$$
